# SAM checkpoints

Place official Segment Anything image-encoder checkpoints in this directory. The released U-SamNet configuration expects:

```text
sam_vit_b_01ec64.pth
```

Download it from the official Segment Anything release:

```bash
wget https://dl.fbaipublicfiles.com/segment_anything/sam_vit_b_01ec64.pth
```

Pretrained weights are excluded from Git and remain subject to their original license and terms.
